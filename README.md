# Retail-Revenue-Analysis
Retail Revenue Analysis is a data analytics project that uses Excel, SQL, Python and Power BI to analyse retail sales, customer behaviour, product performance, store performance and inventory. The project includes data cleaning, SQL analysis, Python-based RFM customer segmentation and an interactive Power BI dashboard

## Project Overview
**Retail Revenue Analysis** is a data analytics project focused on converting retail data into meaningful business insights.
The project analyses **customers, products, stores, orders, sales and inventory** to understand revenue performance, customer purchasing behaviour, product performance and operational efficiency.
The project uses **Excel, SQL, Python and Power BI** across the complete data analytics workflow.

## Objectives
* Clean and prepare retail datasets
* Analyse sales and revenue trends
* Identify top-performing products
* Understand customer purchasing patterns
* Perform customer segmentation using RFM analysis
* Analyse store and staff performance
* Identify low-stock products
* Build an interactive Power BI dashboard

## Project Workflow
**Clean → Store & Query → Analyse → Segment → Visualize → Present**

### 1️ Excel – Data Preparation
* Combined and organized retail datasets
* Removed duplicate records
* Handled missing values
* Standardized date and text formats
* Used VLOOKUP / XLOOKUP to combine related product information
* Checked sales, quantity, price and discount values

### 2️ SQL – Data Analysis
* Applied primary and foreign keys
* Joined Orders, Order Items, Products, Customers, Stores and Staff
* Calculated total sales and revenue
* Identified top-selling products
* Analysed customer spending
* Analysed store and staff revenue
* Created customer segmentation data for Power BI

### 3 Python – Exploratory Analysis
* Imported SQL data using Pandas
* Explored the retail dataset
* Used `df.info()`, `df.describe()` and `df.value_counts()`
* Performed basic data exploration
* Prepared the data for customer segmentation

### 4 RFM Customer Segmentation
RFM analysis was used to understand customer purchasing behaviour.

* **Recency** – How recently a customer purchased
* **Frequency** – How often a customer purchased
* **Monetary** – How much a customer spent
Customer segments were created using RFM scores and the results were prepared for Power BI.

### 5 Power BI – Dashboard
The final dashboard includes:
* Revenue KPI
* Customer KPI
* Product KPI
* Stock KPI
* Average Order Value
* Total Orders
* Sales trends
* Product and category analysis
* City analysis
* Store and staff performance
* Customer segmentation
* Low-stock monitoring
* Interactive filters and date controls
